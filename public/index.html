    03 / METHOD

    How Watchtower thinks

    One signal.
    Six bounded stages.

    Each stage records what was requested, what was observed, and what could not be verified.

    1. 01

      Watch

      Listen only for the approved proxy and upgrade signature.

      EVENT
    2. 02

      Detect

      Bind the exact transaction, block, log, emitter, and decoded implementation.

      TRIGGER
    3. 03

      Investigate

      Read historical state at N−1 and N using the fixed, versioned plan.

      STATE
    4. 04

      Check

      Verify deployed code and only the protocol calls authorized for this profile.

      EVIDENCE
    5. 05

      Decide

      Issue a deterministic corroborated, contradicted, or incomplete disposition.

      RESULT
    6. 06

      Verify

      Recompute the canonical receipt ID and open the underlying Base evidence.

      RECEIPT
