    Investigation method

    Six bounded stages, one receipt

    Each stage preserves what was requested, what was observed, and what could not be verified.

    1. 01

      Event observed

      Verify the configured proxy, transaction, log, topic, and decoded implementation.

    2. 02

      Plan selected

      Choose one versioned deterministic plan with a fixed read budget.

    3. 03

      Historical state checked

      Read the EIP-1967 implementation slot at N-1 and N.

    4. 04

      Implementation checked

      Verify deployed implementation bytecode at the upgrade block.

    5. 05

      Protocol identity checked

      Run only the profile's three approved historical calls.

    6. 06

      Receipt issued

      Bind the trigger, plan, checks, limitations, and disposition into deterministic JSON.
